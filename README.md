# Detroit Health Access Finder

Hackathon project: FastAPI backend + React frontend for querying Detroit school-based health centers.

## Features
- FastAPI backend with `/ask` endpoint
- React frontend (Vite)
- Real Detroit health center data (26 centers)
- Live queries on health center locations and sponsoring organizations

## Run Locally
```bash
python main.py
# Visit http://localhost:8000
```

## Data
- School-based health centers in Detroit from public dataset
- Sponsoring organizations: ACC, Covenant, Henry Ford Health, St. John, Detroit Community Health

## Tech
- Backend: FastAPI, Pandas
- Frontend: React, Vite
- Data: CSV query engine
